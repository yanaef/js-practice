Главное своими словами

Переменные. const по умолчанию. let только если потом пишете имя = ... с новым значением. push и pop не заменяют массив, поэтому const подходит.

Сравнение. === сравнивает значение и тип, == подгоняет типы. Пишем ===. "5" + 2 даёт "52", а "5" - 2 даёт 3.

Условия. В if / else if срабатывает первая подходящая ветка, поэтому узкое условие ставим первым. «Нет» это 0, "", null, undefined, false. Всё остальное «да», включая пустой массив [].

Функции. return отдаёт значение, console.log только показывает. Без return функция отдаёт undefined.

Массивы. Номера с 0. Последний: arr.at(-1). push возвращает длину, pop возвращает убранный элемент.

Шпаргалка по методам
Метод	Что отдаёт	Если не нашёл
includes(x)	true / false	false
indexOf(x)	номер	-1
find(правило)	первый элемент	undefined
filter(правило)	массив всех подходящих	[]
map(правило)	новый массив той же длины	

Проверка «нашлось»: find это if (result), filter это if (result.length > 0).

js
const user = users.find(user => user.name === "Петя");
if (user) { console.log(user.id); }

Объекты. user.name достаёт поле, user.city = "..." добавляет или меняет, delete user.age удаляет. Вложенное: order.customer.city. Перед обращением вглубь проверяем ту коробку, из которой достаём: if (order.delivery).

Ваши частые ошибки
sum[...] вместо sum(...): для вызова нужны круглые скобки.
Слово до => и слово после должны совпадать: user => user.name.
console.log внутри функции вместо return.
<= вместо < в цикле по массиву.
pop внутри цикла по тому же массиву.
let i; без начального значения в for.
Слово undefined пишется именно так.
